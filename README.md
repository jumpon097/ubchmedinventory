# UBCH Med Stock v7 — Knowledge Pages

แพ็กเกจเว็บไซต์งานคลังยา ธีมน้องดอกบัว อัปเดตจาก index เวอร์ชันที่มีระบบสื่อสารด้วยใจและปุ่มลอย LINE/Messenger

## หน้าที่เพิ่ม/ปรับใหม่
- `mixing.html` การผสมยาที่มีอัตราส่วน พร้อม C1V1=C2V2 และจุดทวนสอบ
- `guidelines.html` แนวทางปฏิบัติ พร้อมตัวดูเอกสาร HAD และแนวทางเภสัชกรรม
- `oncall.html` ตารางเวร ON Call พร้อมแนวทางการเรียกและตัวดูเอกสาร
- `index.html` เพิ่มทางเข้า 3 หน้าจาก Sidebar, เมนูมือถือ, การ์ดเด่น และระบบค้นหา

## ติดตั้งบน GitHub/Cloudflare Pages
อัปโหลดไฟล์ทั้งหมดและโฟลเดอร์ `assets` ไปที่ root ของโปรเจกต์ โดยคงชื่อไฟล์เดิม จากนั้น deploy ใหม่

## หมายเหตุ
Google Sites บางหน้าอาจไม่อนุญาตแสดงใน iframe จึงมีปุ่มเปิดเต็มหน้าเป็น fallback ทุกจุด ส่วนเอกสาร Google Drive ใช้โหมด preview และต้องตั้งสิทธิ์ให้ผู้ใช้เป้าหมายเปิดได้
