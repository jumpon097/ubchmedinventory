สิทธิ์ผู้ดูแลระบบ

นำเข้าไฟล์ข้อสอบ จัดการแก้ไข ปรับปรุงคลังคำถาม และดาวน์โหลดโครงสร้างแม่แบบ JSON ไปใช้งานนอกสถานที่

1. นำเข้าแบบทดสอบวิชาอื่นด้วยไฟล์ภายนอก

อัปโหลดไฟล์ JSON ที่รันมาจาก ChatGPT/Claude/Gemini นอกระบบเพื่อสร้างคลังข้อสอบเรื่องอื่นๆ ได้อย่างอิสระ

คลิกเพื่ออัปโหลดนำเข้าคลังแบบทดสอบ (.json)

ไฟล์ข้อสอบของคุณจะต้องเป็นไปตามโครงสร้างมาตรฐานที่เราเตรียมไว้ให้

2. ดาวน์โหลดเทมเพลตมาตรฐาน (JSON Template)

นำโครงสร้างข้อสอบ JSON ดิบนี้ไปป้อนให้ AI (ChatGPT, Gemini, Claude) เพื่อให้ช่วยแต่งโจทย์ บรรจุตัวเลือก และแปลวิเคราะห์ความรู้กลับมาในรูปแบบภาษาไทยทางการแพทย์อย่างสวยงาม

💡 วิธีใช้งานร่วมกับ AI ข้างนอกอย่างคุ้มค่า:

  1. กดปุ่มดาวน์โหลดเทมเพลตมาตรฐานด้านล่าง
  2. เปิดไฟล์และก๊อปปี้เนื้อหาในข้อสอบส่งให้ ChatGPT ภายนอก
  3. สั่ง AI ว่า "โปรดแปลงบทเรียนหรือแต่งโจทย์วิชาใหม่ให้เป็นโครงสร้าง JSON นี้เท่านั้น ห้ามพิมพ์คำอธิบายอื่นนอกวงเล็บปีกกา"
  4. นำไฟล์ JSON ที่ AI สรุปผลลัพธ์มาป้อนอัปโหลดด้านซ้าย

รายชื่อข้อสอบทั้งหมดที่มีในหน่วยความจำ

แสดงคำถาม ตัวเลือก เฉลยข้อที่ถูกต้อง และวิชาหัวข้อย่อยที่มีการบันทึกไว้ในบราวเซอร์อุปกรณ์นี้

สร้างแบบทดสอบชุดใหม่

กรองตามหัวข้อวิชา:
โจทย์แบบทดสอบ หมวดหมู่หัวข้อ จำนวนตัวเลือก เฉลย การจัดการ

คู่มือผู้ใช้และการขยายระบบสำหรับกลุ่มงาน

แอปพลิเคชันเวอร์ชันนี้ได้รับการออกแบบให้ประหยัดพลังงาน ไร้ความกังวลเรื่องโควตา API หรืออัตราการตอบสนองที่ล่าช้าของ AI ด้วยระบบออฟไลน์ที่เสถียรที่สุด 100%

ขั้นตอนการนำไปใช้แต่งข้อสอบวิชาอื่นๆ ด้วยตนเอง

  1. ดาวน์โหลดโครงสร้าง: ไปที่แท็บ 'ระบบหลังบ้าน' แล้วก๊อปปี้เทมเพลตมาตรฐาน JSON ของเรา
  2. ส่งงานต่อให้ AI: นำเทมเพลต JSON นี้ไปพิมพ์ใน ChatGPT โดยระบุความต้องการของคุณ เช่น "ช่วยตั้งคำถามเรื่อง เภสัชวิทยาโรคหัวใจ จำนวน 10 ข้อ ในโครงสร้าง JSON รูปแบบนี้เท่านั้น บรรจุคำอธิบายการแพทย์เป็นภาษาไทยให้ครบถ้วน"
  3. อัปโหลดแบบทดสอบ: นำข้อมูล JSON ดิบที่ ChatGPT สรุปคำตอบกลับมาเซฟเป็นไฟล์แล้วกดนำเข้าในบราวเซอร์ คลังข้อมูลแบบประเมินจะอัปเดตแปรสภาพโดยอัตโนมัติ

คำศัพท์คีย์เวิร์ดทางวิชาการที่สกัดจากรูปภาพ

🧬 Fractional Cell Kill & Log-Kill: อัตราส่วนการทำลายเซลล์มะเร็งด้วยยาเคมีบำบัดในสัดส่วนที่เป็นเปอร์เซ็นต์คงที่ในแต่ละรอบของการรักษา

🛡️ Checkpoint Inhibitors (CTLA-4, PD-1): กลุ่มยาลดระบบหักห้ามกระตุ้น T-cell ทำให้ภูมิคุ้มกันร่างกายกลับมาตื่นตัวจู่โจมทำลายก้อนมะเร็ง

🩸 Myelosuppression: ความเป็นพิษที่มีขอบเขตจำกัดทางขนาดของยาเคมีบำบัด (Dose-limiting toxicity) โดยส่งผลต่อการกดการผลิตเม็ดเลือดแดง-ขาวและเกล็ดเลือดในไขกระดูก
