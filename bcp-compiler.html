🌐 คลังเก็บไฟล์ระบบ BCP (เวอร์ชันล่าสุด)

แอดมินสามารถนำไฟล์ ZIP ที่สร้างเสร็จแล้ว ไปอัปโหลดขึ้น GitHub Pages

☁️ เปิด Google Drive / หรือลิงก์ GitHub ของคุณ

⚙️ ส่วนของแอดมิน (สำหรับอัปเดตฐานข้อมูล)

กรุณาแนบไฟล์รูปภาพและฐานข้อมูล Excel
ระบบจะทำการ ฝังข้อมูลลงไปเป็นเนื้อเดียวกับไฟล์เว็บ
(ข้อมูลที่มีค่า TRUE ในคอลัมน์ I, E, F จะถูกกรองทิ้งให้อัตโนมัติ)
